Harakiri Sandbox
Design System.

Tokens, components, and patterns for an AI-agent sandbox platform. Minimal, light-mode-first, hairline borders, a single sharp accent. Designed to read like Linear or Vercel at first glance — and feel like a terminal under the hood.

1 primary accent 2 typefaces 14 components 5 page templates

Color

01 / foundations

A warm off-white ground and near-black ink, separated by a single hairline border tone. One accent — a deep crimson — that nods to the brand without dragging the rest of the palette into a saturated direction. Everything is defined as CSS custom properties rooted on :root so theming is one rule deep.

Spacing & radii

Elevation

04 / foundations

Three layers. Most surfaces sit flat with a 1px hairline; shadows show up only on floating UI (modals, popovers, toasts). No blurry drop-shadows on hover.

Iconography

05 / foundations

A small custom set of 16×16 line icons, 1.5px stroke, rounded caps/joins. Drawn on a 16-unit grid with 1.5px-aligned anchors. Color follows currentColor.

Buttons

01 / components

Five flavors. Primary is solid ink. Secondary is hairline-bordered. Ghost is transparent until hover. Accent is reserved for go-actions inside flows. Destructive is text-colored, not solid.

01 / code

Core components live in components/shared.jsx. They're plain functions — no hooks, no providers, no theme objects — and pair directly with the CSS classes documented above. Copy what you need.

  <span className="brand" style={{ fontSize: size }}>

    </span>
  </span>
);

const MeterBar = ({ v, max }) => (
  <span className="meter">
    <span className="meter-fill" style={{
      width: Math.min(100, (v/max)*100) + '%',
      background: v > 80 ? 'var(--err)' :
                  v > 50 ? 'var(--warn)' : 'var(--ok)'
    }} />
  </span>
);
