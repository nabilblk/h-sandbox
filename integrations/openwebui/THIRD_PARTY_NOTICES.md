# Open Terminal discovery schema

`open-terminal.openapi.json` is generated from Open Terminal 0.14.6, commit
`431fc2bccf98fd1e197a0d47a5140f495ba017eb`, by `scripts/export-openapi.py`.
The generated execution description omits build-host metadata. Notebooks and
the system-prompt endpoint are disabled to match the reference template.
