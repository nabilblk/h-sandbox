# 0.5.0-rc.11: Task-Oriented TypeScript and Deep Agents

September 23, 2026. Developer Preview on npm `next`; stable `latest` remains
`0.4.0`. Publication evidence is recorded in the
[delivery receipt](0.5.0-rc.11-delivery.md), not inferred from this feature list.

## TypeScript SDK

- `HarakiriClient.fromEnv()` requires your installation URL and a server-side key.
- `sandbox.run(command, { check: true })` returns the command result directly and
  throws `HarakiriRunError` on nonzero exit. Object-input envelopes stay supported.
- Text and byte helpers validate binary length and SHA-256 without allocating
  a per-byte JavaScript array. Transport remains bounded JSON/base64, not streaming.
- Process handles reconnect through sandbox/command IDs without resubmitting.
- Route fetch scopes credentials, preserves Request semantics and uses manual
  redirects. Applications must handle redirects explicitly after upgrading.
- Accepted creation failures retain IDs in `HarakiriSandboxCreationError`.
  This error does not extend `HarakiriApiError`; check the migration guide.
- Cancellable waits bound observation. Cancellation does not kill remote work.
  `kill({ wait: true })` confirms termination and this sandbox's capacity release.
- Workspace handles and Git bootstrap recovery retain explicit ownership.
  No mutation is automatically replayed; distributed exactly-once effects are
  not promised. The OpenCode recipe preserves optional provider credentials.

## Deep Agents Source Preview

The optional `packages/deepagents` backend targets **Deep Agents 1.14.0**. It
is separate from the core SDK and remains unpublished on npm until its initial
publication and package-specific trusted-publisher setup are complete. Do not
run `npm install @h-sandbox/deepagents` expecting this source candidate.

The guide starts with the real `createDeepAgent` import and a runnable repository
repair: inspect files, edit the implementation, rerun unchanged original tests,
retrieve the diff and confirm cleanup. The application hosts reasoning, model
credentials and checkpoints; Harakiri hosts the backend's shell/file tools.
Custom local tools do not become isolated automatically.

The adapter preserves abnormal termination in framework-visible output, exposes
incomplete searches and retains completed transfer paths after cancellation.
Native runtime and real-model qualification are separate from deterministic
framework contract tests; consult the receipt for their results and limitations.

## Install and Compatibility

```bash
npm install --save-exact @h-sandbox/sdk@0.5.0-rc.11
npm install --global @h-sandbox/cli@0.5.0-rc.11
```

The standard SDK workflows require a readiness/capacity-capable API rc.9 or
newer. Usage history requires rc.10 or newer. Existing templates, permissions,
storage and enforcement capabilities still apply. Node 20/22 consumers are
tested; repository tooling uses Node 22. The CLI is republished with its matching
SDK dependency, not advertised as a new set of CLI commands.

No API database migration is added. A full image/chart release retains schema
039 and the existing runtime chart. Preserve operator-owned public OIDC origins,
Secrets, encryption keys and image digests. Client publication does not change
any running installation; it is not a new recovery, HA or OpenShift certification.
