# 0.5.0-rc.6 Delivery

September 9, 2026. Images/chart published; superseded by rc.7. Npm rc.6 was not published.

This candidate follows the immutable rc.5 publication after full container scans
found packages outside the workspace JavaScript dependency audit. The API image
applies Debian security updates and removes unused npm/Yarn; the web image applies
Alpine updates. Publishing refreshes upstream base images. The source chart and
all application/package versions are aligned.

The native evaluation values also correct upstream server/gateway requests that
previously reserved 12 GiB before a sandbox could start. The failed first attempt
is retained, not represented as a successful clean install.

Source/tag: `ba9cb7f1c663faba7ed67630652e6a58d20898d8`, `v0.5.0-rc.6`.
[Harbor workflow 34348759775](https://github.com/nabilblk/h-sandbox/actions/runs/34348759775)
published both image architectures and the chart; source CI passed.

Arm64 container rescans reduced web matches from 177 to 9, and API matches from
221 to 211. No API npm findings or high/critical findings with a published fix
remained in that scan. Unfixed distribution advisories still require operator
review; this is not a zero-vulnerability claim. Web's two remaining high matches
belong to unused TIFF/image-processing dependencies removed in rc.7.

The installed rc.5 CLI reported a hard-coded rc.3 version. This was caught before
publishing rc.6 packages, and its fix plus exact-version assertions belong to the
[rc.7 candidate](0.5.0-rc.7-delivery.md). No rc.6 artifact was overwritten; stable
npm `latest: 0.4.0` remains unchanged. Public opening remains owner-gated.
