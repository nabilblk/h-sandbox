# 0.5.0-rc.14: Protected Services And OpenWebUI

Date: 2026-10-30. Developer preview, not a stable promotion.

## Delivery Status

PR [#78](https://github.com/nabilblk/h-sandbox/pull/78) is merged. Publication and
the guarded public-lab deployment are in progress; verify the delivery receipt
and registry identities before using the coordinates below. No independent
operator installation of the OpenWebUI integration is claimed.

## What Changes

- Generic protected HTTP and WebSocket transport through the Harakiri API and
  runtime-provider gateway, with scoped grants, credential/cookie stripping,
  bounded transfers/connections and live grant revalidation. No pod endpoints
  or Kubernetes exec enter the integration contract.
- TypeScript route helpers and Python sync/async route clients for exposure,
  application-health checks, bounded HTTP requests and scoped WebSocket headers.
- A separate OpenWebUI adapter for the native Open Terminal connection. Durable
  encrypted PostgreSQL bindings map a trusted OpenWebUI user's identity to one
  retained personal workspace per adapter instance. Chats for that user share
  files. The adapter does not add OpenWebUI endpoints to Harakiri's core API.
- A non-root Open Terminal 0.14.6 template with Python, Bash, Git and matplotlib.
  OpenWebUI 0.12.4 remains unmodified. The reference local-model workflow uses
  Ollama and Qwen 3.5 4B without a paid provider key.
- Public guides cover installation, native connection setup, actual chat/tool
  verification, shell, files and previews, secret ownership, retention, failure
  diagnosis, explicit recovery and cleanup.

## Upgrade And Rollback Boundaries

Back up PostgreSQL with its associated Vault key material and retained storage
before upgrading. Preserve operator values, OIDC public URLs, Secrets and PVCs.
Do not run the legacy development installer against a public environment.

Migration `040_protected_route_uniqueness.sql` allows protected routes to share
the API host while retaining uniqueness for active public hosts and active route
keys. It changes indexes, not user rows. Do not run a schema down-migration:
multiple protected routes can now intentionally share a host, so recreating the
old unique index can fail. Coordinate API, scheduler and template-builder images.
Do not roll back the core while adapters depend on its generic WebSockets.
Earlier rc.9/rc.10 recovery receipts are not certification of this new pair.

## Evidence And Limits

[Native run 41017083195](https://github.com/nabilblk/h-sandbox/actions/runs/41017083195)
passed all 22 gates and complete cleanup on Linux amd64, using actual OpenWebUI
and a real local model. The [retained receipt](../operations/evidence/openwebui-41017083195.json)
identifies tested merge source `5148f852b1e65264706859c7f9f2c22df5e450d8`.
Its SHA-256 is `85e2b6056a69974772989b5ef886074e6bd41ea55e0f9041e29ef8cb31a73c05`.
This is source-built qualification, not anonymous published-image acceptance.
The release's later publication and deployment evidence must identify their own
source, run IDs and digests.

One chat generated CSV, exact JSON totals and a verified PNG. Labeled PDF/HTML
renderer fixtures were separately uploaded through the native UI; these are not
claimed model-generated documents. Shell, transfer, hostile-preview isolation,
mobile layout, two-user separation, quota denial, adapter restart, grant
revocation/recovery and retained-file runtime replacement were exercised.
Earlier failed runs remain in the [qualification history](../operations/openwebui-source-acceptance.md).
An earlier pair of native browser errors was not reproduced in later runs; its
root cause is not established and is not presented as fixed.

This preview does not provide new per-resource Harakiri user ACLs, a unified
Open Terminal command audit, per-chat workspace isolation, Office conversion,
notebooks, a hosted model, customer OpenShift certification or production SLA.
Self-contained HTML stays in an opaque-origin preview. Do not weaken cookies,
enable same-origin access or put tokens in asset URLs. Upstream OpenWebUI may
buffer transfers; Harakiri's transport does not make every operation streaming.
